SDK
sdk-tools_preface.sh:::SDK:

The SDK group contains the utilities used to create, maintain, deploy, document, package, and release SolidGroundUX-based projects.

While the framework itself provides the runtime foundation for applications, the SDK tools support the development lifecycle around that runtime. Together they form a lightweight development environment for creating structured Bash applications without having to reinvent the surrounding project administration for every new tool.
