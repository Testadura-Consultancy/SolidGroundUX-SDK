Why These Tools Exist
sdk-tools_preface.sh::SDK:Why These Tools Exist:

Bash projects often begin as a handful of scripts and gradually evolve into collections of loosely related files with inconsistent structures.

The SDK tools attempt to prevent that outcome by encouraging a repeatable workflow and a consistent project layout from the beginning.

In other words, they automate the boring parts of project administration so developers can spend their time building software rather than managing files.
