16. Menu API and Management Console Boundary
sux_epilogue.sh::Subsystem Reference Guide:16. Menu API and Management Console Boundary:

`sgnd-menu.sh` is a reusable Framework library. It owns menu registration, rendering, paging, visibility, input interpretation, and item dispatch. It does not own the SolidGround Management Console application.

The console host, public `sgnd-console` command, page discovery/lazy loading, and management modules belong to the separate MCM product. MCM consumes `sgnd-menu` and other Framework APIs in the same way another application can consume them.
