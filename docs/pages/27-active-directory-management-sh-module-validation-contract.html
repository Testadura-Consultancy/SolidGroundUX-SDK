Return codes:

0 = Passed
1 = Failed
2 = Warning
3 = Skipped / not applicable

Every validator sets SGND_MODULE_VALIDATION_MESSAGE to a concise result summary. Detailed diagnostic output may be written by the validator or delegated action.
