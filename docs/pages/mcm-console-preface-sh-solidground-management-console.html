SolidGround Management Console
mcm_console_preface.sh:::SolidGround Management Console:

The SolidGround Management Console is the interactive administration shell for SolidGroundUX. It is built from a generic console host, a reusable menu engine, and source-only functional modules.

The console deliberately separates discovery from loading. At startup it discovers the available module files and reads only the literal module name and description required to build the main index. The module body is not sourced until its page is selected.

Once a module has been opened it remains loaded for the lifetime of the console process. Returning to the index does not unload it, and opening the page again does not source it a second time.
