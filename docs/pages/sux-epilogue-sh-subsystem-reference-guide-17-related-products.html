17. Related Products
sux_epilogue.sh::Subsystem Reference Guide:17. Related Products:

The Framework documentation ends at the reusable runtime boundary. Development and release tooling belongs to the separate SolidGroundUX SDK product; the management console host and server-management modules belong to SolidGroundUX Management Console Modules. Both consume Framework APIs without becoming Framework subsystems.

Use the SDK documentation for `create-workspace`, `deploy-workspace`, documentation generation, release preparation, release management, and development templates. Use the MCM documentation for `sgnd-console`, lazy-loaded console modules, and module validation.
