SolidGroundUX Codex / sgnd_doc_renderer.py / Python Renderer Backend

Python backend used by the SolidGroundUX documentation pipeline to transform the normalized PSV tables emitted by the Bash processor into the navigable HTML site.

The module is intentionally standard-library only and uses the same SolidGroundUX `# fn:`, `# cls:`, `# var:`, and section-comment dialect as Bash source files.
