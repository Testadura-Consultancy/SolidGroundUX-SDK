Ask the user for input
sux_epilogue.sh::How do I...?:Ask the user for input:

Use ask for a single typed value, ask_choose or ask_choose_immediate for choices, ask_decision for symbolic decisions, and ask_prompt_form for multiple named fields.

Example:

ask_prompt_form --autoalign "${SGND_STATE_VARIABLES[@]}"
