sux_epilogue.sh::How do I...?:Show an auto-continue prompt:

Use ask_dlg_autocontinue for an interruptible countdown. It supports redo, cancel, pause/resume, any-key continuation, and returns distinct status codes.

Example:

ask_dlg_autocontinue --seconds 10 --message "Continuing deployment" --redo --cancel --pause
