Return the usable menu-body height
SolidGroundUX Codex / sgnd-menu.sh / Menu layout measurement / _sgnd_console_body_height
Purpose
Determine how many rendered lines may be allocated to one menu page.
Output
Writes the effective body height to stdout.
Returns
0 after calculating the height.
Usage
