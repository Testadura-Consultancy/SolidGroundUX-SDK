Add generated help examples
sux_epilogue.sh::How do I...?:Add generated help examples:

Add lines to SGND_SCRIPT_EXAMPLES. sgnd_show_help includes these examples when rendering script help.

Example:

SGND_SCRIPT_EXAMPLES=(
"Deploy using defaults:"
" $SGND_SCRIPT_NAME"
""
"Undeploy everything:"
" $SGND_SCRIPT_NAME --undeploy"
)
