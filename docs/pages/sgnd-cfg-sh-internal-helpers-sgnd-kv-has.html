_sgnd_kv_has
SolidGroundUX Codex / sgnd-cfg.sh / Internal helpers / _sgnd_kv_has
Purpose
Test whether a KEY exists in a KEY=VALUE file (even if empty).
Arguments
$1 File path.
$2 Key (must be a valid identifier).
Returns
0 if present,
1 if not present,
2 on argument/read error.
Usage
