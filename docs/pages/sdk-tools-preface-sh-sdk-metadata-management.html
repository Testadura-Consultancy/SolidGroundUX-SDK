Metadata Management
sdk-tools_preface.sh::SDK:Metadata Management:

Metadata plays an important role within the SolidGroundUX ecosystem. Version, build, checksum, attribution, licensing, and source identity are maintained through the canonical source-header model.

Metadata maintenance is consolidated into prepare-release.sh and the shared header-parser support. Version and Build can be updated for all files, changed files only, or left untouched, while checksums are refreshed whenever source or release metadata changes require it.

Keeping this work in release preparation avoids a separate metadata-maintenance tool and ensures the release artifacts and source headers are synchronized together.
