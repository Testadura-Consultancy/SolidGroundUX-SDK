style_hints - Documentation line markers and style hints
doc-sample.sh::::style_hints

The plain documentation marker is:

> Plain documentation line
> When used without text, emits an intentional blank line

Style hints are presentation hints layered on top of the structural content type. The renderer reads the exported stylehint value for each documentation line. When the style hint is normal, no additional style class is added. When another value is supplied, the renderer adds a corresponding sh-<stylehint> CSS class.

The currently supported style hints are:

normal Standard rendered text
label (:) Label or small subheader text
highlight (.) Highlighted text
emphasis (!) Emphasized text
underline (_) Underlined text
quote (~) Quoted or aside text
listitem (-) Bullet-style list item
indent Reserved indentation style
