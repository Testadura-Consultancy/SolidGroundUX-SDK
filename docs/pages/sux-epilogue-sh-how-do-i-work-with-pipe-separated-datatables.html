Work with pipe-separated datatables
sux_epilogue.sh::How do I...?:Work with pipe-separated datatables:

Use sgnd-datatable.sh when data is represented as schema and pipe-separated rows. It provides helpers for splitting schemas/rows, validating values, inserting, deleting, getting, setting, finding, sorting, printing, and exporting PSV data.

Example functions:

sgnd_dt_make_row
sgnd_dt_insert
sgnd_dt_get
sgnd_dt_set
sgnd_dt_find_first
sgnd_dt_print_table
sgnd_dt_export_psv
