Evaluate whether a menu/framework flag is enabled
SolidGroundUX Codex / sgnd-menu.sh / Internal helpers / _sgnd_flag_is_on
Arguments
$1 Value to evaluate.
Returns
0 for 1, true, yes, or on (case-insensitive variants currently supported).
1 otherwise.
Usage
_sgnd_flag_is_on "${FLAG_DRYRUN:-0}"
