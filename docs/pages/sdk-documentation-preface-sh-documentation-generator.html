Documentation Generator
sdk-documentation_preface.sh:::Documentation Generator:

Documentation-only sources may live in the canonical `usr/local/share/solidgroundux/doc-sources` directory of any product. Full recursive generation discovers them like other supported source files; their Product, Group, and Subgroup metadata controls logical placement rather than their physical directory. Product-prefixed basenames are recommended because module identity is basename-based.

The Documentation Generator subgroup contains the tools used to extract, process, render, and generate SolidGroundUX documentation.

The documentation system is built around the idea that documentation should live close to the code it describes. Instead of maintaining a separate manual by hand, source files contain structured comment blocks that can be converted into a navigable HTML documentation set.

The file doc-sample.sh demonstrates the supported documentation conventions and should be treated as the practical reference for writing documentation comments.
