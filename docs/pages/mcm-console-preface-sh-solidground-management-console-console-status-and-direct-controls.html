Console Status and Direct Controls
mcm_console_preface.sh::SolidGround Management Console:Console Status and Direct Controls:

The status area shows framework-owned runtime state. These controls are available directly from the console and are not implemented as module menu items:

M Toggle DRY-RUN / COMMIT
A Toggle STANDARD / ROOT access by relaunching the console
c / C Cycle console log level forward / backward
f / F Cycle file log level forward / backward
t / T Cycle installed theme forward / backward
Shift+S Open a shell
L Set lines per page
R Reset last-run result markers for the current module page
Ctrl+R Re-measure the terminal, invalidate layout caches, and redraw

The toggle bar is status; the legend is navigation/help. These direct controls replace the former Console Settings menu/module. Functional modules should not duplicate them or depend on a Console Settings page being loaded.
