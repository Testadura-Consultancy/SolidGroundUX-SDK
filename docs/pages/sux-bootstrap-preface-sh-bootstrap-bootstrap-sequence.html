Bootstrap Sequence
sux-bootstrap_preface.sh::Bootstrap:Bootstrap Sequence:

Startup proceeds in this order:

executable
-> _framework_locator
-> sgnd-exe-common
-> sgnd-bootstrap
-> bootstrap environment
-> configuration and state
-> libraries declared in SGND_USING
-> application main

`_framework_locator` is intentionally self-contained. It runs before the normal Framework libraries are available and locates `sgnd-exe-common.sh`. The executable common layer then provides the early runtime needed to enter `sgnd-bootstrap`.
