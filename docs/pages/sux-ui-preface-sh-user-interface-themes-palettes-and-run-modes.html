Themes, Palettes, and Run Modes
sux-ui_preface.sh::User Interface:Themes, Palettes, and Run Modes:

Styling is resolved centrally. Palettes define named colors and visual roles, while themes determine how those roles are applied by the rendering functions. This prevents consuming scripts from embedding ANSI codes or hard-coded color choices.

The active style can reflect the current run mode, such as normal operation, dry-run execution, debugging, or another framework-defined state. Applications communicate intent through the public API; the UI layer selects the appropriate visual representation.

When styling is disabled or unsupported, UI functions should degrade to readable plain text without changing the semantic content of the output.
