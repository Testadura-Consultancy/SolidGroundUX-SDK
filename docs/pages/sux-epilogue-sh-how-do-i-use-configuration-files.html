Use configuration files
sux_epilogue.sh::How do I...?:Use configuration files:

Add configuration-driven variables to SGND_SCRIPT_GLOBALS. When this array is non-empty, sgnd_bootstrap applies script configuration through sgnd_cfg_domain_apply. Readable system/user cfg files are loaded automatically at startup. Missing domain files can be created by the cfg layer.

Example:

SGND_SCRIPT_GLOBALS=(
)
